# Graphite

Самостоятельная локальная тема Neovim: `:colorscheme graphite`.
Плагин Catppuccin для загрузки не нужен. Начальная палитра и таблицы подсветки
адаптированы из Catppuccin Mocha; лицензия сохранена в `LICENSE-Catppuccin`.

- `palette.lua` — цвета синтаксиса и роли интерфейса.
- `editor.lua` — редактор, диагностика, поиск и стандартные окна.
- `syntax.lua` — Vim syntax, Treesitter и семантические токены LSP.
- `languages.lua` — исключения для отдельных языков; дополняйте по `:Inspect`.
- `integrations.lua` — используемые плагины, вкладки, меню, diff и статус агента.
- `init.lua` — загрузка темы и оформление lualine.
- `pi.json` — порт темы для Pi Agent; цвета задаются в его `vars`.

Pi подключает файл через `~/.pi/agent/themes/graphite.json`, ссылающийся на
`pi.json`. Тема выбирается в `/settings` → Theme → `graphite`.
Палитра JSON перенесена из `palette.lua`; последующие изменения Lua-палитры
нужно также переносить в `vars` JSON. Фон всего терминала тема Pi не меняет:
для совпадения с Graphite установите в эмуляторе `#1e1e1e`.

Цвета в палитре уникальны и все используются. Для общих поверхностей есть
`background`, `selection` и `muted`; прежних дублей `base`/`mantle`/`crust`
и `surface0`/`surface1`/`surface2` нет. HEX-значения задаются только в палитре.
Группы редактора, включая diff, определены в `editor.lua`, без повторных
переопределений в интеграциях. Близкие оттенки синтаксиса, диагностики и поиска
сохранены: они различают категории текста и состояния.

Для изменения цвета меняйте палитру и перезапускайте Neovim. Простое повторение
`:colorscheme graphite` применяет загруженные таблицы; редактирование самих Lua-модулей
требует перезапуска. Никакой компиляции темы и внешнего кэша нет.

Lazygit получает цвета рамок и выделения из highlight-групп через Snacks.
`themes/delta.lua` берёт фоны diff из активной темы. Для Graphite используется
встроенная в delta синтаксическая палитра `Catppuccin Mocha`, соответствующая нашей
исходной палитре. При дальнейших изменениях синтаксических цветов эту внешнюю
палитру потребуется адаптировать отдельно.
