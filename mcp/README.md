# Fude Review MCP

Локальный stdio MCP-сервер для `flexphere/fude.nvim`, на официальном Python SDK.
Работает на macOS и Linux. Сетевой порт не открывает.

## Запуск и проверка

```sh
uv sync --project mcp --python 3.12
mcp/.venv/bin/python mcp/fude_review.py
uv run --project mcp pytest mcp/tests -q
uv run --project mcp ruff check mcp
```

Для регистрации в агенте используйте абсолютные пути к `mcp/.venv/bin/python`
и `mcp/fude_review.py`. В каждом вызове инструментов передавайте абсолютный
`cwd` нужного проекта; рабочая директория MCP-процесса не используется.

## Инструменты

- `list_threads`: текущая сессия ветки, фильтры `status`, `file`, `author`, `query`, пагинация.
- `get_thread`: вся дискуссия, диапазон строк, контекст и `version`.
- `reply_to_thread`: ответ агента с сохранением истории.
- `resolve_thread` / `reopen_thread`: смена статуса.

Изменения требуют `session_id`, `thread_id`, `expected_version`, `request_id`.
Для каждого нового действия нужен новый `request_id`; при повторе того же запроса
используется прежний ID. Ответ на изменение содержит новую версию треда.
После `VERSION_CONFLICT` перечитайте тред и оцените изменения, прежде чем повторять
действие. `SESSION_CHANGED` означает, что пользователь переключил ревью.

Сервер не создаёт сессии, не редактирует исходники, не удаляет комментарии
и не работает с GitHub PR. Начните локальное ревью в nvim через Alt+r.

## Согласованность с редактором

Python-сервер и `lua/utils/fude_lock.lua` используют `flock` на
`.fude/.mcp.lock` одного worktree. Адаптер подключается из конфигурации fude:
он защищает append/read журнала и обновления указателя активных сессий.
Сервер проверяет версию и дописывает событие под тем же lock; повтор запроса
не создаёт дубль. Lock-файл не удаляется, блокировка освобождается при закрытии
дескриптора, в том числе после завершения процесса.

После установки адаптера перезапустите все nvim, работающие с этим ревью.
Старые экземпляры и сторонние скрипты, пишущие JSONL напрямую без lock, не входят
в этот протокол. Проверки не защищают от внешнего `git checkout` посреди вызова;
не переключайте ветку во время записи агентом. Повреждённый или оборванный журнал
не исправляется автоматически: сервер откажется его менять.

Восстановление состояния проверяется тестом совместимости с родным
`fude.local.store.materialize`. При обновлении формата хранилища fude этот тест
нужно запускать снова. Автоперечитывание редактора настроено на 10 секунд;
для немедленного обновления используйте `:FudeReviewReload`.
